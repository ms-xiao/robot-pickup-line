One pickup line, in a robot's voice, for make.fun's "The Robot Pickup Line Championship": a single line of at most 200 characters, judged head to head by an AI judge. The line is in `entry.txt`; `main.ts` (Node, standard library only) prints it and writes the identical bytes to `/output/entry.txt`.

> I scanned 8 billion humans. You're the only one my spam filter let through.

## Run it

```sh
node main.ts
```
